# WATCH OUT
### BUILD. DEFEND. STRIKE. (v2.0.0)

**WATCH OUT** is a clean, colorful 3D isometric city-builder and territorial defense strategy game. Build connected road networks, pastel residential neighborhoods, commercial plazas, industrial ports, and utilities while safeguarding your city with early-warning radar towers, SAM batteries, and offensive airbase operations.

---

## What's New in Version 2.0.0

- **Clean Isometric City-Builder Aesthetic**: Narrow-FOV isometric camera angle, bright sunlit lighting, azure water, golden beaches, smooth green terrain, soft slate-grey roads, and simple, elegant low-poly pastel buildings.
- **Genuinely Connected Roads & Intersections**: Automatic node snapping, mid-segment T-junction splitting, automatic 4-way crossing splits, trimmed curbs, dashed lane markings, zebra crosswalks, and bridges over water.
- **Cohesive Low-Poly Architecture**: Pastel suburban homes with red, blue, and orange roofs, mid-rise apartments, blue glass office towers, a central fountain park with cherry-blossom trees, a factory with a red-and-white smokestack, a harbor with shipping containers and a red gantry crane, and a defense compound with a white spherical radome tower.
- **Authoritative Air Defense Simulation**: Radars and SAM batteries detect threats, rotate and elevate their 3D launcher turrets to track targets, launch visible interceptor missiles, and destroy aerial threats in mid-air.
- **Streamlined UI**: Compact top bar with essential resources and simulation speed controls, one small bottom-left tutorial card, and a simple 5-tab bottom construction toolbar (`Roads`, `Residential`, `Commercial`, `Industry`, `Defense`), keeping advanced panels hidden until needed.

## Controls

| Action | Control |
| :--- | :--- |
| **Pan Camera** | `W`, `A`, `S`, `D`, Arrow Keys, or Left/Middle-Click + Drag |
| **Orbit / Tilt Camera** | Right-Click + Drag |
| **Zoom In / Out** | Mouse Scroll Wheel |
| **Rotate Building Preview** | `R` Key |
| **Cancel Placement / Deselect** | `ESC` Key or Right-Click |
| **Inspect Building** | Left-Click on any 3D Building |

## How to Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
